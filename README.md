# program_kadai_1_23

Unity製の2Dアクションゲームです。

## ゲーム概要

プレイヤーが自動で右に進みながら、スペースキーで敵を倒してスコアを稼ぐゲームです。
ゴールに到達するとリザルト画面が表示されます。

## 操作方法

| キー | 操作 |
|------|------|
| スペースキー | 攻撃（近くの敵を1体倒す） |

※プレイヤーは自動で右に進みます。

## ゲームの流れ

1. ゲーム開始 → プレイヤーが自動で右に移動
2. スペースキーで近くの敵（範囲1.5ユニット以内）を攻撃
3. 敵を倒すごとに100点獲得
4. ゴールに到達 → リザルト表示・リスタート可能

## 開発環境

- **Unity**: 6000.0.41f1
- **言語**: C#
- **対応OS**: Windows / Mac

## プロジェクトの開き方

1. Unity Hub を起動する
2. 「Open」→ このフォルダを選択する
3. Unity 6000.0.41f1 で開く
4. `Assets/Scenes/SampleScene.unity` を開く
5. 再生ボタンで動作確認できる

## ファイル構成

```
Assets/
├── Scripts/          # ゲームスクリプト（C#）
│   ├── PlayerController.cs   # プレイヤーの移動・攻撃
│   ├── GameManager.cs        # スコア管理・UI
│   ├── Enemy.cs              # 敵の動作・死亡処理
│   ├── EnemySpawner.cs       # 敵の配置（20体）
│   ├── EnemySimpleBT.cs      # 敵AIのビヘイビアツリー
│   ├── Goal.cs               # ゴール判定
│   ├── ResultManager.cs      # リザルト画面
│   ├── HitEffect.cs          # ヒット演出（フラッシュ・スロー）
│   └── CameraFollow.cs       # カメラ追従
├── Scenes/           # シーンファイル
└── Prefabs/          # 敵プレハブ
```

## スクリプト説明

### PlayerController.cs
プレイヤーの動きを管理します。
- 一定速度で右に移動し続ける
- スペースキーを押すと周囲1.5ユニット以内の敵を1体攻撃する

### GameManager.cs
ゲーム全体の状態を管理します。
- スコアと倒した敵の数を記録・表示する
- ゴール到達時にリザルト画面を呼び出す

### EnemySpawner.cs
ゲーム開始時に敵を20体配置します。
- 敵同士が近づきすぎないよう、最低3ユニットの間隔を保って配置する

### HitEffect.cs
攻撃ヒット時の演出を管理します。
- 画面フラッシュ・パーティクル・タイムスロー（0.1倍速）を再生する
